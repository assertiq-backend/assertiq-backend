## 🧩 Current Platform: AssertIQ

**AssertIQ** is an AI QA platform designed to act like an autonomous QA engineer.

The platform connects to real applications, inspects the current UI state, generates or reuses page methods, validates them against runtime evidence, repairs selector failures, and saves successful methods as trusted memory.

```text
User Story
→ Feature / Scenarios
→ Step Wrappers
→ Page Methods
→ Runtime Validation
→ Self-Healing
→ Trusted Memory
→ Reuse
```
